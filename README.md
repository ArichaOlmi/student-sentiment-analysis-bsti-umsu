# Student Sentiment Analysis for BSTI UMSU

A text-based sentiment analysis system for evaluating student satisfaction toward Information Systems and Information Technology (IS/IT) services at Universitas Muhammadiyah Sumatera Utara (UMSU) using **TF-IDF** and **Multinomial Naïve Bayes**.

## Research Overview

This project develops a sentiment classification system to analyze student feedback regarding BSTI UMSU services.

The system classifies student comments into three sentiment categories:

- Positive
- Neutral
- Negative

The methodology includes:

- Text preprocessing
- TF-IDF feature extraction
- Multinomial Naïve Bayes classification
- Manual sentiment labeling
- Streamlit-based visualization dashboard

## Experimental Results

| Metric | Score |
|--------|-------|
| Accuracy | **72.03%** |
| Weighted F1-score | **0.6870** |

## Installation

Clone repository:

```bash

```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run application:

```bash
streamlit run Home.py
```
