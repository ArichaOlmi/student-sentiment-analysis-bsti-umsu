Langkah menjalankan apliksi pada VS Code (digunakan pada seluruh pengujian): 
a. Buka VS Code → File → Open Folder… lalu pilih Folder project (mis. 
D:\Kuliah\Skripsi\sentimen-umsu). 
68 
b. Buka Terminal baru: Terminal → New Terminal. 
c. Aktifkan virtual environment: .venv\Scripts\activate 
d. Jalankan aplikasi: streamlit run Home.py --server.port 8502 
e. Buka browser pada alamat Local URL yang muncul (mis. 
http://localhost:8502).
